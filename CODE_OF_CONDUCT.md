# Code de conduite

*This project is written and documented in French. Reports are welcome in English too.*

Serenity est un petit projet. Ce texte n'est pas là pour faire joli dans l'onglet Community, il
dit ce qui est attendu de tout le monde, y compris du mainteneur.

## Ce qu'on attend

- **Sois direct sur le code, correct avec les personnes.** Une revue sévère est utile, une
  remarque humiliante ne l'est jamais.
- **Explique ton raisonnement.** « C'est faux » ne sert à rien. « C'est faux parce que le bloc
  est rejouable sans la révision dans les données associées » fait avancer tout le monde.
- **Une question de débutant est une bonne question.** La crypto, l'isolation des conteneurs et
  la rotation transactionnelle sont compliquées. Personne ne naît en les sachant.
- **Accepte un non.** Le périmètre du projet est tenu court, volontairement. Un refus porte sur
  une idée, pas sur toi.

## Ce qui n'est pas accepté

- Les insultes, les attaques personnelles, le mépris affiché.
- Le harcèlement, sous toutes ses formes, en public comme en message privé.
- Les remarques sexuelles, racistes, sexistes, validistes, ou visant l'origine, la religion,
  l'identité de genre ou l'orientation de quelqu'un.
- Publier des informations privées sur une personne sans son accord.
- Exploiter le projet pour nuire : publier une faille avant son correctif, ou pousser du code
  qui exfiltre des données.

## Où ça s'applique

Partout où le projet vit : issues, pull requests, revues de code, discussions, et tout espace où
quelqu'un se présente comme faisant partie de Serenity.

## Signaler

Écris au mainteneur par un message privé GitHub, ou par l'onglet **Security** du dépôt si le
problème touche à la sécurité. Un signalement reste confidentiel.

Le mainteneur répond, tranche, et peut selon la gravité : demander de reformuler, modifier ou
supprimer un message, fermer une discussion, ou bloquer un compte. Il s'applique les mêmes
règles qu'aux autres.

Ce texte s'inspire du [Contributor Covenant](https://www.contributor-covenant.org/fr/), en plus
court et dans les mots du projet.
